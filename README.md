# Project ECHO 

基于 Unity 引擎开发的俯视角 Roguelike 弹幕射击游戏原型。本项目专注于展示高度解耦的系统架构、数据驱动的能力构筑以及高性能的客户端基建。

## 技术栈
- 开发引擎：Unity 2022.3.6f1c1
- 编程语言：C#
- 渲染管线：Universal Render Pipeline
- 核心插件：PlayerInput System, TextMeshPro
- 版本控制：Git
- 架构设计：策略模式、单例模式、观察者模式、对象池模式

## 核心系统与功能实现

### 1. 物理介质交互系统
- **介质附着**：支持电荷、高热、流体三种独立物理状态。具备独立计时器、状态衰减与内置冷却机制，防止高频逻辑死循环。
- **交互矩阵**：
  - 传导：电与水结合，实现空间索敌的连锁闪电伤害。
  - 过载：电与热结合，实现带有物理推力的能量爆炸。
  - 气化：热与水结合，生成战术烟幕，实现致盲逻辑与机体强制冷却。
  - 爆燃：热与油结合，生成持续伤害的火海区域。
- **动态环境生成**：场景包含可破坏介质桶，击破后动态生成水渍或油渍。利用射线检测算法确保敌人、障碍物及液体区域精准贴合地面。
- **战术火控系统**：自动锁定射程内最近敌人，并内置战术优先级逻辑，特定范围内优先攻击介质桶以触发物理反应。

### 2. 软硬件双轨构筑系统
- **二进制内存管理**：引入 1024MB 内存换算标准。严格区分永久固件与内存协议，内存上限限制协议安装，支持内存对齐奖励与超频惩罚逻辑。
- **模块化硬件挂载**（未实装）：
  - 枪管位：决定单发、散射、射线等子弹形态与基础产热。
  - 核心炉：决定基础内存带宽与生命上限。
  - 散热组件：决定位移散热系数与环境冷却加成。
- **数据驱动能力库**：基于策略模式的高度解耦架构，支持通过装配逻辑零件组合新能力卡片，实现诸如触发传导反应时回复生命值等因果联动引擎。
- **分级抽卡算法**：能力池自动根据白、蓝、紫、红品质等级对协议进行归类，并支持根据权重比例的随机抽取算法。

### 3. 游戏流程与框架
- **程序化节点地图**：多分支路径选择机制，支持普通战斗、精英遭遇、随机事件（未实装）、首领战等多种节点生成。
- **数据驱动波次**：基于 ScriptableObject 的战斗波次生成，配合动态清理机制管理战场残留物。
- **跨场景持久化**：全局单例实现血量、已装配协议、内存负载等核心数据的跨场景无缝保留与 UI 自适应重连。

### 4. 客户端性能优化
- **通用对象池系统**：基于字典与队列的子弹及特效回收机制，全面替代实例化与销毁操作，规避运行时垃圾回收导致的性能峰值。
- **事件驱动 UI 架构**：利用 C# 静态事件实现血量、内存、日志反馈的解耦刷新，避免在更新函数中进行高频轮询。
- **视觉信息反馈**：
  - 飘字系统：支持暴击缩放位移，物理反应发生时弹出专属强调文字。
- **URP 渲染适配**：项目整体采用通用渲染管线，支持高性能光照与粒子特效表现。


## 快速开始
- **环境要求**：Unity 2022.3.6f1c1 或更高版本。
- **启动场景**：请打开 `Assets/_Scenes/MainMenu.unity` 运行游戏。
- **操作方式**：
  - WASD：移动
  - E 键：场景交互
